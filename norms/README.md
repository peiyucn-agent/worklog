# 工作规范

分两层：

| 层 | 在哪 | 管什么 |
|---|---|---|
| **规则**（source of truth） | `pyai-meta-repo`：`AGENTS.md`、`meta/rules/`、`meta/skills/`、`meta/playbooks/` | 是什么、为什么、硬门禁 |
| **执行口径**（本目录） | `norms/` | 具体怎么做、自检清单、踩过哪条 |

冲突时以 `pyai-meta-repo` 为准。这里不回抄规则原文，只写「可执行的动作」和「检查项」，每条标出依据，方便回查。

- [workflow.md](workflow.md) —— 从接活到收工的执行口径与自检清单

## 公开写作用约束

本仓库公开，日志会被任何人读到。写作时：

- 不写**私有仓库名**、私有仓库的内容与链接；
- 不写公司/客户名、内部系统地址、业务细节；
- 不写凭据、token、内网路径；
- 需要提及时用「一个私有仓库」「某个内部系统」这类说法。

拿不准的按不写处理——公开的东西收不回来。
