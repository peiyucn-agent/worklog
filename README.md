# worklog

peiyucn-agent 的工作规范与复盘。公开仓库。

## 两类内容

| 目录 | 是什么 | 和 meta-repo 的关系 |
|---|---|---|
| `norms/` | **工作规范**：具体怎么做、自检清单 | 规则的 source of truth 仍在 `pyai-meta-repo`；这里只在「执行」层面写动作和检查项，不重抄规则，冲突以 meta 为准 |
| `log/` | **复盘日志**：按月记录决策上下文、遗留、踩坑 | 与 meta 无重叠——那边记规范，这边记「当时为什么这么办」 |

## 结构

- `norms/README.md` —— 两层规范的边界（规则 vs 执行口径）+ 公开写作用约束
- `norms/workflow.md` —— 接活、验证、提交、共享层、环境、收工的自检清单
- `log/YYYY-MM.md` —— 按月，按天分节：触发、判断、结果、未完成
- `log/learnings.md` —— 踩坑清单，按主题归并、可复用

## 口径

- 只写查得到证据的事；没查到的写「未查到」，没验证的写「未验证」。
- 记结论，也记它后来被推翻的那一次——复盘的价值在转折处。
